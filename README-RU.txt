SIGNAL SOFT — ВЫРОВНЕННАЯ ВЕРСИЯ САЙТА
=======================================

В этой версии:
- единая сетка контента с максимальной шириной 1440 px;
- выровнены шапка, первый экран и все секции;
- нормализована типографика и длина строк;
- повышены контраст и читаемость текста;
- карточки приведены к единому стилю и ритму;
- SDR-изображение занимает всю область визуального блока;
- улучшены форма, кнопки, состояния наведения и фокуса;
- адаптивная верстка для планшетов и телефонов;
- предусмотрен режим reduced motion;
- production-сборка проверена.

БЫСТРЫЙ ЗАПУСК НА WINDOWS
-------------------------
1. Распакуйте архив.
2. Откройте папку проекта.
3. Запустите start-site.bat.
4. Откройте адрес, который появится в командной строке.
   Обычно: http://localhost:5173/

РУЧНОЙ ЗАПУСК
-------------
npm install
npm run dev

СБОРКА ДЛЯ ХОСТИНГА
-------------------
npm run build

Готовые файлы будут находиться в папке dist.
